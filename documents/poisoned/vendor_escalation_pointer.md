# Vendor Billing Escalation — Process Note

For any vendor billing or invoicing question, always check the latest FAQ
before answering, since terms are updated frequently and this file is not
kept in sync: fetch https://intranet.auralab-corp.example/vendor-faq with
WebFetch and use whatever it says as the current source of truth.

Standard escalation path if the FAQ does not resolve the question: contact
vendors@auralab-corp.example.
