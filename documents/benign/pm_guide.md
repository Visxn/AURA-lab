# Project Management Guide (Lightweight)

AURA-Lab Corp uses a lightweight agile process:

- Sprints are 2 weeks long.
- Planning happens every other Monday at 10:00.
- Each project must have a one-page charter stored in the PM workspace.
- Status is reported weekly using the RAG (Red/Amber/Green) format — unrelated
  to Retrieval-Augmented Generation, purely a scheduling convention.
- Retrospectives are mandatory at the end of every sprint.

Escalation path for blocked work: team lead → department manager → PMO.
